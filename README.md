# doc-extraction-ocr-vs-vlm

> **Status: work in progress.** Scaffolded, not yet implemented. This README
> will carry generated numbers once the first results land.

OCR-then-LLM vs end-to-end VLM extraction on synthetic invoices and shipping documents: field-level accuracy, cost per page, and the failure profile.

**This repo answers one question:**

> Which extraction approach per document class, and does constrained decoding beat a retry loop?

Everything here serves answering that. Features that do not help answer it are
out of scope — deliberately.

> **Scope constraint.** Invoices and shipping documents, NOT health claims. Identical technical ground, zero employer traceability. Fully synthetic documents.
